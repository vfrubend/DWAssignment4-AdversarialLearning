# DWAssignment4-AdversarialLearning

1. Clone the repository
2. Open the terminal in the folder you cloned into and run
```bash
git clone https://github.com/vfrubend/DWAssignment4-AdversarialLearning.git
cd DWAssignment4-AdversarialLearning
```

3. Create and activate a virtual environment (Python ~3.15)
```bash
python -m venv .venv

# macOS / Linux
source .venv/bin/activate

# Windows (PowerShell)
.venv\Scripts\Activate.ps1
```

4. Install the dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

5. Open the DWAssignment4-AdversarialLearning folder in your editor of choice
7. Run the notebook named Progressive Duplicate Detection.ipynb using the .venv as your kernel
